# Нестадо

Гра з корівами Неллі. Три коріви впали за холодильник, і їх треба повернути назад.

Грати: відкрий index.html через будь-який хостинг (GitHub Pages, Netlify, Cloudflare Pages).
Локально двічі клацнути не вийде, потрібен сервер: `python3 -m http.server` у цій папці.

Керування: WASD або стрілки, пробіл стрибок, E здібність, 1 2 3 перемикання корів. На телефоні джойстик і кнопки.

Моделі корів зроблені за авторськими роботами Неллі. Права на образи корів належать авторці.
